## 🚀 Quick Tech Stack Summary

- **Frontend Framework**: React 18 with TypeScript & Vite
- **Styling & UI**: Tailwind CSS, Lucide React Icons, Canvas Confetti
- **Backend & API**: Express.js server (`server.ts`) with Vite middleware
- **Database & Auth**: Firebase Firestore & Firebase Auth (`asia-southeast1`)
- **Progression & Gamification**: Local-first storage sync with real-time Firestore persistence
- **PWA & Offline Support**: Web App Manifest, Service Worker integration, PWA install prompts
