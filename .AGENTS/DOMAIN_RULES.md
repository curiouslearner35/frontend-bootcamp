# Domain Rules & Core Contracts — Curious Learners

## 1. The Git-First Pedagogy Contract

- **Philosophy**: *"LEARN GIT BEFORE LEARNING CODE"*.
- Week 00 and Week 01 strictly focus on Git CLI concepts (staging, commits, branches, merges, remotes, merge conflicts).
- AI agents modifying curriculum data must maintain Git CLI as the mandatory introductory weeks before web programming.

---

## 2. Practice Sandbox & Homework Verification Contract

- **Source of Truth**: The `task` object generated by `src/services/taskGenerator.ts` for each lesson.
- **Contract Rules**:
  1. **Requirement-Level Validation**: Each requirement in `activeTask.requirements` MUST be evaluated individually against the user's code and live execution state.
  2. **PASS / FAIL Semantics**:
     - Satisfied requirement: `PASS` badge (✓) with green border/background.
     - Unsatisfied requirement: `FAIL` badge (✕) with red border/background and actionable fix hint (`💡 Fix: ...`).
  3. **No Fake Pass**: Homework or lesson practice must NEVER be marked as complete unless ALL requirements evaluate to `true` (`allRequirementsMet === true`).
  4. **No Arbitrary Host Code Execution**: Code execution occurs strictly inside a sandboxed `<iframe>` environment.

---

## 3. Terminal Emulator Contract

- **Emulated Environment**: Fish Shell + Oh My Posh powerline prompt simulator.
- **Intentional Interaction Boundary**:
  - `Tab Navigation ≠ Terminal Interaction`.
  - Switching to the Terminal tab MUST ONLY switch the active tab view.
  - MUST NOT automatically focus the terminal text input on mount or tab switch.
  - MUST NOT automatically execute any CLI command or trigger soft keyboard popups.
  - Focus MUST occur strictly when the student intentionally clicks or taps inside the terminal container.
  - Activity tracking (`TERMINAL_COMMAND`) MUST occur strictly on actual command execution.
- **Dynamic TUI System Clock**:
  - Rendered via `<LiveTerminalClock />` using runtime date/time (`new Date().toLocaleTimeString(...)`).
  - Updates every 1 second (1000ms).
  - Must clean up interval (`clearInterval`) on component unmount to prevent duplicate timers or memory leaks.

---

## 4. Dual Language (i18n) Contract

- All user-facing strings must support both English (`en`) and Bengali (`bn`).
- Translation definitions reside in `src/i18n/translations.ts`.
- Fallback sequence: `translation[language] || translation['en'] || ''`.
